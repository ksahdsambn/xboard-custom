# 账号删除数据删除与保留矩阵

删除是真实删除/匿名化，不是停用或退出。Xboard 账号删除不会取消 Google Play 订阅。

| 数据 | 处理 | 期限与依据 |
| --- | --- | --- |
| 邮箱、Telegram、密码、UUID、订阅 token | 匿名化 | 立即；个人标识不再需要 |
| 设备登记、公告已读 | 删除 | 立即；非法定保留 |
| 工单主题与消息 | 匿名化并关闭 | 立即 |
| Sanctum 会话 | 全部撤销 | 立即 |
| 套餐/分组/到期/流量 | 清空并封禁 | 立即；阻止 Profile 与登录 |
| `v2_order` | 隔离保留 | 7 年；交易审计 |
| Play 令牌账本、权益投影、RTDN | 隔离保留 | 7 年；退款与争议；令牌只存哈希 |
| Play 账号绑定 | 撤销但保留行 | 保持唯一约束 |
| 删号请求 | 保留 `retain_until` | 7 年；删除审计 |

开发政策，不是生产法律意见。Play 购买验证留给 TASK-030。
